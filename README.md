# ⏱️ Interactive Stopwatch Web Application

An interactive and user-friendly stopwatch web application developed as part of my **Web Development Internship**. The application allows users to accurately measure elapsed time, pause and resume the stopwatch, reset the timer, and record individual lap intervals.

## 🌐 Live Demo

**[View the Live Stopwatch](https://shreyapolicepatil27-droid.github.io/SCT_WD_2/)**

## 📌 Project Overview

The Interactive Stopwatch is a browser-based application designed to provide accurate and easy-to-use time tracking. It demonstrates the practical use of **HTML, CSS, and JavaScript** to create an interactive web application with real-time updates and user controls.

## ✨ Features

* ▶️ **Start** – Starts the stopwatch.
* ⏸️ **Pause** – Temporarily stops the stopwatch.
* 🔄 **Reset** – Resets the stopwatch to zero.
* 🏁 **Lap Tracking** – Records individual lap intervals while the stopwatch is running.
* ⏱️ **Millisecond Display** – Displays minutes, seconds, and milliseconds.
* 📋 **Lap History** – Displays recorded lap times in an organized list.
* 📱 **Responsive Design** – Works across desktop, tablet, and mobile screen sizes.
* ✨ **Interactive UI** – Provides a clean and user-friendly interface with button animations.

## 🛠️ Technologies Used

* **HTML5** – Structure of the web application
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Stopwatch logic, event handling, timer calculations, and lap tracking

## ⚙️ How It Works

The stopwatch uses JavaScript time calculations to track the elapsed time.

When the user starts the stopwatch, the application records the starting time and continuously calculates the difference between the current time and the starting time.

The lap functionality calculates the difference between the current elapsed time and the previous lap time, allowing users to measure individual time intervals.
