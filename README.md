# ⏱️ Interactive Stopwatch Web Application

A simple, interactive, and user-friendly stopwatch web application built using HTML, CSS, and JavaScript.

## 🚀 Features

- ▶️ Start the stopwatch
- ⏸️ Pause the stopwatch
- 🔄 Reset the stopwatch
- 🏁 Record lap times
- ⏱️ Display minutes, seconds, and milliseconds
- 📱 Responsive design for different screen sizes
- ✨ Modern and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
